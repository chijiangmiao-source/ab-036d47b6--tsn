# 机载以太网发布门控调度 —— 冻结裁决台

录入稳定审计标识、整数微秒门控周期、至多 8 条流（优先级 / 周期 / 发送时长 / 截止期）
与按时间排序的门控项；提交后在页面读取冻结裁决。

## 调度语义

- **单出口、非抢占**：帧一旦开始发送必定发完，门控变化不打断发送。
- **严格优先级**：数值越大越高（7 最高，IEEE 802.1Q 约定），同优先级 FIFO。
- **门控**：按门控周期循环，仅放行列明的优先级；帧若不能在关门之前**完整**发送则继续等待。
- **跨周期遗留**：未发送帧跨门控周期保留；同流新释放帧追加到队尾，**不覆盖**未发送帧。
- **超期**：实际发送完成时间 > 释放时间 + 截止期。
- **收敛**：在超周期（门控周期与各流周期 LCM）边界比较队列签名：
  - 边界排空或签名重复 → 收敛，给出稳态模板内**全部流按期发送**的逐帧证据，
    或**首个超期帧**的释放/入队/起止发送时间与逐段阻塞来源
    （更高优先级、同优先级 FIFO、低优先级非抢占、门未放行、放行窗口太短）；
  - 连续超周期边界未完成工作量（队列 + 发送中剩余）严格增长 →
    以连续增长的队列证据 **REJECTED_QUEUE_GROWTH** 拒绝，不截断模拟判通过。

## 冻结语义

- 完全相同的提交（同一审计标识、内容哈希一致）或重复读取，返回**同一冻结结论**；
- 不同内容复用同一审计标识 → `409 AUDIT_ID_CONFLICT`，响应携带且存储保留**原裁决不变**；
- 裁决持久化于 `/data/verdicts.json`（容器卷 `verdict-data`），重启后结论不变。

## 运行

```bash
docker compose up --build web        # http://localhost:8000
```

页面可录入 / 提交 / 读取冻结裁决，并展示逐时隙的出口队列快照、门状态与发送结果。
修改任意输入或提交失败都会立即清除页面上的旧裁决。

接口：

- `POST /api/submit` 提交并冻结；
- `GET  /api/verdict/{audit_id}` 读取冻结裁决；
- `GET  /api/health` 健康检查。

## 一次性验收

```bash
docker compose build
docker compose run --rm verify
```

`verify` 服务执行后退出：先字节码构建检查，再运行代码测试（pytest），
最后对审计接口做 HTTP 冒烟——验证**跨周期遗留帧收敛按期证据**（含冻结幂等与冲突保持）
与**队列连续增长拒绝**场景，以退出码报告结果。

无 Docker 时可本地执行同一脚本：

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python verify.py
```
